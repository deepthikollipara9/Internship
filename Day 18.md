#How to Install Power BI Desktop

1) Go to the official website:Visit the [Power BI Download page](https://www.microsoft.com/en-us/power-platform/products/power-bi/desktop).
2) Click on “Download Free”
3) You’ll be redirected to the Microsoft Store where you can install Power BI Desktop.
4) Install via Microsoft Store
5) Click the “Get” or “Install” button to begin installation. It’s free.
6) Alternative: Download as an EXE installer
If you prefer a direct setup file (for older Windows versions), scroll down and click “See download options”. Choose the .exe file for your system (32-bit or 64-bit).
7) Run the installer and complete setup
8) Follow the on-screen steps to install Power BI Desktop on your machine.
9) Launch Power BI Desktop
10) After installation, open Power BI and you’re ready to get started.
11) Preview the Data (Optional)
12) You can click on a table or sheet to preview the data on the right-hand side.

#How to Import an Excel Dataset in Power BI

1) Open Power BI Desktop
2) Click “Get Data”
3) Found in the Home tab on the ribbon.
4) Select “Excel” from the data sources
5) Browse and choose your Excel file
6) Select sheets or tables you want to import
7) Click “Load” to bring the data into Power BI
8) Start building your visualizations!
9) Use the fields pane and report canvas to explore your data.
