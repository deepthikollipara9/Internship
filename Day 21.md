# Day 21 - 6 March 2025

1) To explore each chart type with [official documentation](https://learn.microsoft.com/en-us/power-bi/consumer/end-user-dashboards)
2) Column Chart (Clustered / Stacked)
     -Go to Visualizations pane → Click on Clustered Column Chart icon.
     -Drag a categorical field (e.g., Product) to the Axis.
     -Drag a numerical field (e.g., Sales) to the Values.
     -To stack by category, add a second field to the Legend.
     -[More about](https://learn.microsoft.com/en-us/power-bi/visuals/power-bi-visualization-column-charts?tabs=powerbi-desktop)
3) Bar Chart
    -Similar to column charts but horizontal.
    -Choose Clustered Bar Chart icon.
    -Axis and Values fields are used the same way.
    -[More about](https://learn.microsoft.com/en-us/power-bi/visuals/power-bi-visualization-combo-chart?tabs=powerbi-desktop)
4) Line Chart
    -Click the Line Chart icon.
    -Drag Date or Time to the Axis.
    -Drag Sales or any numerical value to Values.
    -Optionally, add Region or Category to Legend for multiple lines.
    -[More about](https://learn.microsoft.com/en-us/power-bi/visuals/power-bi-line-chart?tabs=powerbi-desktop)
5) Pie or Donut Chart
    -Click the Pie Chart icon.
    -Drag Category (like Region) to Legend.
    -Drag Sales or Count to Values.
    -[More about](https://learn.microsoft.com/en-us/power-bi/visuals/power-bi-visualization-doughnut-charts?tabs=powerbi-desktop)
6) Table / Matrix
    -Click on Table or Matrix visual.
    -Add multiple fields to Values.
    -In Matrix, you can also add row/column groups.
    -[More about](https://learn.microsoft.com/en-us/power-bi/visuals/power-bi-visualization-matrix-visual?tabs=powerbi-desktop)
7) KPI Visual
    -Useful for tracking a target.
    -Click on KPI visual.
    -Drag main metric to Indicator, time field to Trend axis, and target metric to Target goal.
    -[More about](https://learn.microsoft.com/en-us/power-bi/visuals/power-bi-visualization-kpi?tabs=powerbi-desktop)
8) Card
    -Great for displaying single summary values.
    -Choose Card icon.
    -Drag Total Sales or similar KPI field to Values.
    -[More about](https://learn.microsoft.com/en-us/power-bi/visuals/power-bi-visualization-new-card)
9) Area Chart / Stacked Area Chart
    -Similar setup to line chart.
    -Shows volume changes across time or categories.
10) Scatter Plot
    -Click Scatter Chart.
    -X-axis and Y-axis must both be numeric.
    -Can use Category or Product in Details or Legend.
