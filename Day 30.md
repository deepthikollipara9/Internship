# Day 30 - 21 March 2025

1) Launch Tableau Desktop from your system.
2) On the Start Page, select "Connect to Data".
3) Click on "Microsoft Excel", CSV, or another source under “Connect”.
4) Browse and select your dataset
5) Tableau loads your file and shows a Data Source tab.
6) After loading, click on the "Sheet 1" tab at the bottom.
7) You’ll see the Data pane on the left and an empty canvas.
8) Create a New Visualization
    -Drag a dimension(e.g., Category, Region)to Columns or Rows.
    -Drag a measure(e.g., Sales, Profit)to the opposite shelf.
    -Tableau automatically selects a chart type based on the fields.
9) Customize the Chart
    -Use the Marks card to modify visual types(e.g., Bar, Line, Pie).
    -Drag fields into Color, Label, Tooltip, Size, or Detail.
    -Format titles: Double-click chart title -> Edit.
    -Right-click axis or labels -> Format to change font, color, etc.
10) Apply Filters
    -Drag a field to the Filters shelf.
    -Choose which values to include or exclude.
    -Right-click the field -> Show Filter.
11) Explore Common Chart Types
    -Bar Chart: Dimension on Columns, Measure on Rows.
    -Line Chart: Time (e.g., Date) on Columns, Measure on Rows.
    -Pie Chart: Set Marks to “Pie”, drag dimension to Color and measure to Angle.
    -Map: Drag a geographic field (e.g., Country) to the view.
    -Scatter Plot: Use two numeric measures, one on Columns, one on Rows.
    -Table/Crosstab: Drag multiple fields to Rows and Columns, show text.
    -Area Chart: Like a line chart, but change Marks type to Area.
    -Histogram: One numeric field to Columns, COUNT or SUM to Rows.
    -KPI: Use calculated fields and bold numbers with color indicators.
12) Create Dashboards
    -Click the Dashboard tab at the bottom.
    -Drag worksheets into the dashboard view.
    -Add filters, legends, text boxes, and interactions.
13) Click File -> Save As to save your .twb or .twbx file.
14) To publish: Go to Server -> Tableau Public / Tableau Server
