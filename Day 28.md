#Download and Install Tableau
1) Go to the Official [Website](https://public.tableau.com/app/discover)
2) Click on “Download Tableau Public”
3) The download will start automatically based on your OS
4) Install the Application
    -Locate the .exe (Windows) file in your Downloads folder.
5) Double-click to begin installation.
6) Follow the on-screen instructions to complete setup.
7) Create a Free Account
8) Sign up or log in using your email to use Tableau Public.
9) This account is used to save dashboards online.


#How to Import an Excel Dataset into Tableau
1) Open Tableau Desktop
2) Go to File -> New to open a fresh workbook.
3) Click on “Microsoft Excel”
4) In the Connect panel (left side), choose Microsoft Excel as your data source.
5) Navigate to the folder and select your Excel file
6) Tableau will show all the available sheets. Drag and drop the one(s) you need into the canvas.
7) View the data to verify column names, data types, and make any changes if needed.
8) Click on “Sheet 1” to Begin Visualizing
9) Opens the worksheet area where you create visualizations.
10) Drag Fields into Columns and Rows
     -Use Dimensions (e.g., Region) in Rows
     -Use Measures (e.g., Sales) in Columns
11) Used the Show Me panel to select from charts like bar, line, pie, maps, etc.
12) Use filters, color legends, labels, and sorting to refine your visuals.
13) Click on the Dashboard tab -> drag sheets to layout -> arrange for interactivity.
14) Save locally or use Tableau Public/Tableau Server for publishing.
