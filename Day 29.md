# Day 29 - 19 March 2025

1) Start with Tableau Official [Documentation](https://help.tableau.com/current/pro/desktop/en-us/gettingstarted_overview.htm)
2) Use this to explore how different chart types work with examples.
3) Bar Chart (Vertical/Horizontal)
    -Drag a dimension (e.g., Category) to Columns.
    -Drag a measure (e.g., Sales) to Rows.
    -For a horizontal bar, switch Columns and Rows.
    -[More aboute](https://help.tableau.com/current/pro/desktop/en-us/buildexamples_bar.htm)
4) Line Chart
    -Drag Date to Columns and Sales to Rows.
    -Tableau auto-detects the best line format.
    -Add a Category to Color to see multiple lines.
    -[More about](https://help.tableau.com/current/pro/desktop/en-us/buildexamples_line.htm)
5) Pie Chart
    -Drag a dimension (like Region) to Rows.
    -Drag a measure (like Sales) to Angle and Color.
    -Change the mark type to Pie in the "Marks" card.
    -[More about](https://help.tableau.com/current/pro/desktop/en-us/buildexamples_pie.htm)
6) Scatter Plot
    -Drag Sales to Columns and Profit to Rows.
    -Drag a dimension like Category to Color or Shape.
    -Use Detail to show each data point individually.
    -[More about](https://help.tableau.com/current/pro/desktop/en-us/buildexamples_scatter.htm)
7) Area Chart / Stacked Area
    -Start with a line chart setup.
    -On the Marks card, change type from Line to Area.
    -For stacked area, include a Category on Color.
    -[More about](https://help.tableau.com/current/pro/desktop/en-us/buildexamples_area.htm)
8) Table / Crosstab
    -Drag dimensions to Rows and Columns.
    -Add a measure to Text in the Marks card.
    -For better formatting, use “Show Me” > Text Table.
    -[More about](https://help.tableau.com/current/pro/desktop/en-us/buildexamples_text_table.htm)
9) Map Visualization
    -Drag a geographic field like State to the view.
    -Drag Sales to Color for a filled map.
    -Tableau auto-detects location if the data is clean.
    -[More about](https://help.tableau.com/current/pro/desktop/en-us/maps_build.htm)
10) Histogram
    -Drag a measure to Columns.
    -Right-click and select “Convert to Dimension” if needed.
    -Drag Number of Records to Rows.
    -[More about](https://help.tableau.com/current/pro/desktop/en-us/buildexamples_histogram.htm)
11) KPI / Single Number Card
    -Drag a measure like Total Sales to Text in Marks card.
    -Format for large display.
    -You can use calculated fields to add logic.
    -[More about](https://www.tableau.com/about/blog/2017/9/how-build-kpi-dashboard-tableau-75774)
