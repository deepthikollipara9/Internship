# Day 22 - 7 March 2025

1) Open Your Power BI File
    -Launch Power BI Desktop.
    -Open your existing .pbix file or import a dataset (e.g., Excel or CSV).

2) Load Dataset
    -Go to Home → Get Data → Excel (or your format).
    -Select the file → Choose the sheet/table → Click Load.

3) Add a New Visualization
    -In the Visualizations pane, select the chart type you want (e.g., bar chart, pie chart, line chart).
    -A blank chart placeholder appears on your canvas.

4) Drag Fields to Build Your Chart
    -Categorical fields to Axis / Legend / Category.
    -Numeric fields to Values / Size / X or Y axis.
5) Apply Filters
    -Use the Filters pane to narrow down data by field, such as region, year, or product category.
6) Customize the Chart
    -Click on the chart → Go to Format (paint roller icon).
    -Rename titles (Title → Text).
    -Change color themes (Data colors).
    -Adjust labels and tooltips (Data labels, Tooltip).
    -Enable gridlines or axes (X-Axis, Y-Axis).
7) Explore Chart Types One-by-One
    -Column Chart: for comparing categories side by side.
    -Bar Chart: horizontal version of column chart.
    -Line Chart: ideal for showing trends over time.
    -Area Chart: line chart with filled areas.
    -Pie/Donut Chart: shows proportions of a whole.
    -Table / Matrix: display detailed row-level data.
    -Card: shows one key metric (e.g., total sales).
    -KPI: shows performance vs target.
    -Gauge: visualizes performance within thresholds.
    -Scatter Plot: shows correlation between two numeric fields.
8) Save and Share
    -Go to File → Save As.
    -You can also publish to Power BI Service (cloud) from the Home tab.
